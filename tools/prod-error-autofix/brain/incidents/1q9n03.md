# BLOG · api · 1q9n03

**Outcome.** fix lane disabled — analysed and reported, no MR

**Root cause.** shopifyRetryApi's retry classifier only recognises HTTP status codes embedded in the error message, so a socket-level `RequestError: read ECONNRESET` from shopify.asset.get inside getAppBlocks is thrown on attempt 0 with zero retries, even though the call site asked for maxRetry=10.

**Mechanism.** appBlockController.blockLoader calls getAppBlocks (appBlockController.js:50) → getAppBlocks wraps shopify.asset.get(themeId, {asset:{key:'config/settings_data.json'}}) in shopifyRetryApi(handler, 0, 10) (shopifyService.js:748). Shopify's edge reset the TCP socket, so shopify-api-node's got client threw a RequestError with code ECONNRESET and no HTTP response. shopifyRetryError (shopifyService.js:161-168) reads only `headers['retry-after']` and `message.includes(429|430|502|503)`; an ECONNRESET has no response headers and no status in its message, so it returns 0. shopifyRetryApi then hits `if (!retry || attempt >= maxRetry) throw new Error(e)` at shopifyService.js:147 on the very first attempt — the maxRetry=10 budget is never spent. `new Error(e)` stringifies the got error, which is why the logged message carries the double prefix `Error: RequestError: read ECONNRESET` and why `e.code === 'ECONNRESET'` is destroyed before any caller can classify it. The error propagates to blockLoader's catch (appBlockController.js:104), which logs severity ERROR — firing this alert — and answers HTTP 200 with `{data: [], error}`, which is why the requests read (httpRequest.status>=500) is empty. The sibling GraphQL helper already does this correctly: shopifyRetryGraphQL retries on RETRYABLE_CODES including 'ECONNRESET' (helpers/api.js:137-144, 165), so three other ECONNRESETs in the same 24h survived as `[shopifyRetryGraphQL]` warn/error lines without failing their requests. The REST path has no equivalent. Secondary defect on the same path: the recursive call at shopifyService.js:149 omits maxRetry, so any retry that does happen silently reverts the budget from the caller's 10 to the default SHOPIFY_MAX_RETRY=50.

Confidence: `medium`
