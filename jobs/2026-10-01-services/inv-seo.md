## Top 3 chạy được TODAY trên URL bất kỳ (<1 ngày glue)

1. **Page SEO audit by URL** — `crawlPageData({url})` (`helpers/seoSpeed.js:239`) → `analyzeCrawlPages` (`:331`) cho issue cấp site; cộng `auditOnPage` `Runner.audit({shopifyDomain: host, keyword, html})` (`services/auditOnPage/runner.js:17`) cho score theo keyword. Đã có HTTP: `POST /proxy/seo-audit`. Glue: wrapper nhận URL → fetch HTML → gọi 2 hàm → JSON. Không Shopify, không AI.
2. **Speed / Core Web Vitals report** — `GET /lighthouse/auditNew?url=…&device=mobile` (`controllers/lightHouseController.js:164`, đang public) hoặc `getGooglePageSpeedScore({url})` (`helpers/google.js:76`). Thêm `extractCriticalCSS({url})` (`extractCriticalCssService.js:793`) làm deliverable "critical CSS cho dev của khách". Agentic score cần cherry-pick từ `feat/agentic-browsing-score`.
3. **Image SEO pack (nén + alt AI)** — `compressImage({srcBuffer, settings})` (`helpers/optimize/sharp.js:164`) + `getImageAlt({shopId:'ext-<tenant>', prompt:{imageUrl, language, resourceTitle}})` (`services/aiContent/index.js:75`). Endpoint nén đã có `/proxy/temp/seo-tool/image`. Glue: crawl `<img>` từ bước 1 → batch alt + nén → trả ZIP/CSV. Không write-back.

Sát nút hạng 4: **AI meta title/description** — `generateMetaTags({pageData, lang})` (`chains.js:259`); chỉ cần map HTML crawl → `pageData`. Hạng 5: keyword research `getKeyWordsSuggestion` (`googleAdService.js:73`).

## Ghi chú fleet / rủi ro (cho techlead)

- 2 endpoint đang public không auth, đúng là 2 engine bán được: `/proxy/temp/seo-tool/image` (sharp) và `/lighthouse/auditNew` (puppeteer). Trước khi bán phải đặt auth + rate limit + metering, không thì đang cho free + tốn GCF.
- `/proxy/seo-audit` auth bằng key cross-app đã lộ trên npm → mọi bên ngoài gọi được; cần key per-tenant nếu thương mại hóa.
- Model AI: code mặc định Ollama `gemma4:31b` (trial); giá thành/1 call phải đo trên provider prod thực tế (env `AI_CONTENT_MODEL`/`IMAGE_ALT_MODEL` ở CI var, chưa kiểm).
- Engine "HIGH" (image pipeline, speed-up theme, sitemap, JSON-LD Liquid, MCP, Sidekick) là phần merchant trả tiền trên Shopify — port sang Woo/Magento = viết adapter write-back per-platform, mỗi cái L.
